Review the entire finance dashboard as if you are the lead product designer for a premium consumer finance application competing with Monarch Money, Copilot Money, and YNAB.

Do not redesign the application from scratch. Keep the existing architecture, routing, data model, APIs, and styling system. Improve the product experience.

Focus on the following:

1. Reduce visual clutter and improve information hierarchy.
2. Reorganize the left navigation into logical groups or collapsible sections instead of one long list.
3. Reduce oversized empty states (Goals, Liabilities, etc.) and replace them with compact, informative cards.
4. Improve Overview cards by adding meaningful context (trend, comparison, or sparkline) when real historical data exists. Never fabricate trends.
5. Replace the cash flow progress bars with a more meaningful financial visualization such as a waterfall, stacked comparison, or similar.
6. Expand the Reports page into a true analytics dashboard with trends, comparisons, category analysis, merchant analysis, subscriptions, budget variance, savings rate, and net-worth history.
7. Improve Budget rows to reduce horizontal scanning and make each budget easier to read.
8. Redesign Account cards into premium financial account cards with institution, account type, masked account number, balance, last updated, and overflow actions.
9. Replace row-level Edit buttons throughout the app with contextual overflow menus where appropriate.
10. Replace the "Attention Required" card with an intelligent Financial Insights card that surfaces useful observations and warnings.
11. Improve Upcoming Bills actions (Mark Paid, Edit, Skip, etc.) instead of "Reopen".
12. Add global search across transactions, merchants, accounts, bills, and categories.
13. Introduce a floating Quick Add action for common operations (Expense, Income, Transfer, Bill, Goal, Investment).
14. Create a dedicated AI Assistant dashboard that proactively summarizes spending, forecasts savings, highlights unusual expenses, and answers natural-language finance questions.
15. Improve visual polish, spacing, empty states, loading states, accessibility, and responsive behavior while preserving the current design language.
16. Verify all financial calculations, percentages, and totals for correctness before displaying them.

Do not make arbitrary UI changes. Every modification should improve usability, reduce cognitive load, or better communicate financial information. The final result should feel like a polished commercial product suitable for everyday personal finance management.
